# Design tools (dev-time only)

Small Python scripts that regenerate the brand artwork from its sources, so derivatives stay consistent
(docs/DESIGN.md sec. 1A, 12.0). They are **not** part of the app: the site has no build step and never runs these.
Requirements: Python 3, Pillow, and fontTools for the seal (`pip install --user pillow fonttools`).

| Script | Makes | Command |
|---|---|---|
| `trace_mascot.py` | Flat-vector poses in `assets/mascot/` from the source renders in `design/mascot/deer/` (brand-palette snap, one fur shade step, traced and smoothed) | `python design/tools/trace_mascot.py design/mascot/deer/<pose>.png assets/mascot/<pose>.svg 512 0 12 1.1` |
| `build_seal.py` | `assets/brand/seal.svg`, `seal-mono.svg` (outlined Fraunces lettering, same geometry as `js/modules/brand.js`) | `python design/tools/build_seal.py` |

Every committed pose was made with exactly the command above; re-running it reproduces the file byte for byte.
One exception adds an opt-in sample group (7th argument), so groups never change poses traced without them:

| Pose | Extra group | Why |
|---|---|---|
| `chalking-up`, `backpacker` (Brand Pass), `traveller-passport`, `dyno` (Phase 5) | none | |
| `topped-out-flag` (Phase 5) | `granite` | the grey boulder needs granite + one shade, or its shadows snap to forest |
| `field-notes`, `fresh-stamp` (2026-10-03) | `ground` | the source's soft beige ground shadow (bottom 14% of the image only) is background, not a cream ellipse |

Background is only what is connected to the image edge: enclosed white inside the character (eye whites and highlights,
chalk, socks, a map pin's hole) is traced as white. Real gaps between limbs are listed in `POCKETS` in the script as a
point inside each gap (source 1024px coordinates), so they stay transparent:

| Pose | Pockets kept transparent |
|---|---|
| `dyno` | between thigh and shorts |
| `chalking-up` | between arm and leg; inside the bucket handle |
| `backpacker` | beside the suitcase; inside its handle; between the feet |

All five poses were re-traced with this rule on 2026-09-29 (before it, every near-white pixel was dropped, so eye whites
were holes that showed the dimmed page behind the milestone sheet).

After tracing, compare the result with the source at full size and at 96px, on a checkerboard (holes show), before committing.

Hand-drawn marks (`assets/mascot/head.svg`, `stamp-head.svg`, `assets/brand/antlers.svg`, `icons/`) are traced by hand
against the source and overlay-checked; they are not generated by these scripts.

## Page header art (`page_art.py`)

`python design/tools/page_art.py` writes `assets/art/regions-wall.svg`, `log-still-life.svg` and `me-shelf.svg` (DESIGN.md sec. 13A).
Seeded, so a re-run is byte-identical; edit the script, never the SVGs. Same rules as the traced poses: ink outline, flat
fills, character palette, no gradients. Keep the subject inside the central 960 x 420 of the 1260 x 540 artboard (the page
crops to 3:1 and 16:9).
