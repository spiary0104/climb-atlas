## Main sources
- Each gym's or chain's own site (fetched directly with a plain HTTP client; for chains with JSON/JS location data the structured data on the page was read).
- Coordinates: OSM elements found through Nominatim name search (one request per 3+ seconds, descriptive User-Agent), Nominatim house-number matches, and the gym's own published map pins (schema.org geo, Squarespace mapLat/mapLng, Movement location list, Google Maps place pins linked from the gym's own page).
- Lead discovery: indoorclimbinggym.com state/city pages, 99boulders.com and indoorclimbing.com state lists (older, 2021-22), Nominatim keyword searches in state bounding boxes. Directories were used for leads only, never for open status.
