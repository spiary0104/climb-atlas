Climb Atlas — one-time seed

Generates a SQL script from every spot in js/data.js that upserts them into your Supabase spots table. Safe to re-run — it matches on id, so re-running just re-syncs the seed rows rather than duplicating them.

This has to run in the Supabase SQL Editor, not from this page directly. The seed rows need to go in as already-approved, but schema.sql's moderation policy deliberately only lets the public anon key insert a spot as status = 'pending' — and Supabase's secret/service_role key is flatly rejected the moment it's used from a browser (a hard security check on Supabase's side, not something this page can work around). The SQL Editor runs as the Postgres superuser and bypasses row-level security entirely, the same way a service_role key would — without ever putting that key in a browser.

  1. Click "Generate SQL" below.
  2. Click "Copy to clipboard."
  3. In your Supabase project: Dashboard → SQL Editor → New query → paste → Run.
