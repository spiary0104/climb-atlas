Climb Atlas — geocode addresses

Every spot's address field was individually verified (see docs/architecture.md "Seed data sourcing"), but for most of them the lat/lng pin position was never recomputed from that address — it's still the original city/suburb-level estimate. This page re-geocodes every spot that has a real street address against OpenStreetMap's Nominatim (free, keyless — no API key/account needed, consistent with this project's map itself), shows how far each proposed position is from the current pin, and lets you review and accept corrections one at a time rather than applying anything blind.

Nominatim's usage policy caps requests at ~1/second and asks for a contact email or referer on bulk personal use — this runs sequentially with a 1.1s delay per request, so geocoding all ~600 addressed spots takes roughly 10–15 minutes. Map data © OpenStreetMap contributors.
